# Bosch 생산라인 불량 집중 스테이션 분석

자동차 부품 118만 개의 생산라인 기록에서 불량이 몰리는 스테이션을 찾고, 그것이 불량의 원인인지 결과인지를 검증해 **개선 우선순위**를 도출했습니다.
**부품의 2%만 지나는 스테이션 L3_S32에 전체 불량의 16%가 집중**됐고, 앞 라인·투입 전 측정값·생산 시기를 통제해도 효과가 유지되어 S32를 1순위 점검 대상으로 제안합니다.

## 결과 요약

| 항목 | 결과 |
|---|---|
| L3_S32 통과 부품 불량률 | **4.51%** (95% 신뢰구간 4.25~4.77%), 미통과 0.50%의 **9.0배** |
| 불량 집중도 | 부품의 2.1%가 통과, 전체 불량 6,879개 중 1,106개(**16.1%**) |
| 생산 시기 통제 후 배수 | **9.3배** (Mantel-Haenszel), 20개 시기 구간 모두 2배 이상 |
| 투입 전 측정값 차이 | S29·S30 측정값 121개 중 차이 있는 값 0개 (최대 SMD 0.13) |
| 경로 정보만으로 예측 | 51개 경로 특징이 측정값 968개와 동등한 예측력 (PR-AUC 0.045 vs 0.043) |

## 목적
불량을 예측하는 모델보다, **어느 공정을 먼저 점검해야 하는지** 판단 근거를 만드는 것이 목적입니다.

## 데이터
- 출처: Kaggle Bosch Production Line Performance (실제 생산라인 데이터, 측정 항목명은 익명화)
- 부품 1,183,747개, 불량 6,879개 (**불량률 0.58%**)
- 측정값 968개 (`train_numeric.csv`, 2.1GB), 측정 시각 1,156개 (`train_date.csv`, 2.9GB)
- 열 이름 `L3_S32_F3850` = 라인 3 / 스테이션 32 / 측정 항목 3850 → 라인 4개, 스테이션 50개(시각 기준 52개)
- 부품마다 거치는 스테이션이 달라, 측정값이 있는 스테이션 = 그 부품의 공정 경로

## 분석 과정

### 1. 대용량 데이터 축소
5GB를 한 번에 읽을 수 없어 5만 행씩 나눠 읽으며, 부품별 **스테이션 통과 여부**와 **스테이션별 진입 시각**만 추출했습니다 (5GB → 약 330MB).

### 2. 불량 집중 스테이션 탐색
스테이션별로 통과 부품과 미통과 부품의 불량률을 비교했습니다. 통과 부품이 적은 스테이션은 불량률이 우연히 튈 수 있으므로, **95% 신뢰구간(Wilson) 하한이 전체 평균보다 높은 경우만** 집중 스테이션으로 판정했습니다.

| 스테이션 | 통과 부품 | 불량률 | 미통과 대비 |
|---|---|---|---|
| **L3_S32** | 24,543 | **4.51%** | **9.0배** |
| L1_S24 | 183,727 | 0.83% | 1.5배 |
| L3_S38 | 27,142 | 0.78% | 1.4배 |
| L2_S26 | 227,011 | 0.75% | 1.4배 |
| L2_S27 | 120,729 | 0.68% | 1.2배 |

S32 외 4곳은 1.2~1.5배로 신호가 약해, 우선순위는 S32 하나로 판단했습니다.

### 3. S32는 원인인가, 결과인가
S32가 불량을 **만드는** 공정인지, 이미 문제 있는 부품이 **보내지는** 공정(재작업·재검사)인지에 따라 결론이 정반대가 되므로 네 가지로 검증했습니다.

**① 공정 흐름상 위치** — 시각 순서상 S32 직전은 S29·S30, 직후는 S33~S36이며, S32가 마지막 스테이션인 경우는 4.4%. 라인 끝에 붙은 재작업 공정이 아니라 **S30 이후 일부 부품만 들르는 곁가지 경로**입니다.

**② 앞 라인별 비교** — 어느 라인을 거쳐 왔든 S32를 지나면 불량률이 높아, 특정 앞 라인이 원인이라는 가능성은 배제됩니다.

| 앞 경로 | S32 미통과 | S32 통과 |
|---|---|---|
| L1 경유 | 0.86% | 3.15% |
| L2 경유 | 0.66% | 4.41% |
| L1·L2 안 거침 | 0.44% | 3.62% |
| L1+L2 둘 다 | 0.57% | 8.06% |

**③ 투입 전 측정값 비교** — S30을 지난 부품 중 S32로 간 24,500개와 안 간 1,095,311개를 S29·S30 측정값 121개로 비교했습니다. 표본이 커서 미세한 차이도 유의하게 나오므로 유의성 대신 **표준화 평균차(SMD)**로 차이의 크기를 봤고, 0.2(작은 차이) 이상인 측정값은 0개였습니다. 측정값 121개를 모두 넣어 S32행 여부를 예측해도 **AUC 0.584 ± 0.001**로 무작위(0.5)에 가까워, 측정값으로 문제 부품을 골라 보냈다는 근거는 약합니다.

**④ 생산 시기 통제** — S32가 라인 전체가 불안정하던 기간에 주로 쓰였다면 시기 탓일 수 있으므로, 생산 시기를 부품 수가 같은 20구간으로 나눠 같은 시기 안에서 비교했습니다. 시기 통제 전 9.0배, 통제 후 **9.3배**로 유지됐고 20개 구간 모두 2배 이상(4.0~18.4배)이었습니다.

### 4. 추가 발견: S32 상태가 특정 기간에 급격히 악화
S32 미통과 부품의 불량률은 전 기간 0.2~0.9%로 안정적이었지만, **S32 통과 부품의 불량률은 구간 6~10에서 6.5%→12.5%까지 급등**한 뒤 마지막 구간에서 1.6~1.8%로 회복됐습니다. 라인 전체가 아닌 S32에만 나타난 변화로, 설비 상태 악화 후 정비·조정으로 회복된 패턴과 유사합니다.

### 5. 경로 정보의 예측 가치 검증
불량률 0.57%에서는 전부 양품이라 답해도 정확도 99.4%가 나오므로 **PR-AUC**로 평가했습니다 (무작위 기준 = 불량률 0.0057). 30만 개 무작위 샘플, HistGradientBoosting, 3-fold 교차검증.

| 입력 | PR-AUC | 무작위 대비 | 학습 시간 |
|---|---|---|---|
| 측정값 968개 | 0.0425 ± 0.0047 | 7.5배 | 40초 |
| **경로 51개** (스테이션 통과 여부 + 통과 수) | **0.0451 ± 0.0023** | **7.9배** | **3초** |
| 측정값 + 경로 | 0.0478 ± 0.0065 | 8.4배 | 24초 |

어느 스테이션을 지났는지만 담은 51개 특징이 측정값 968개와 동등한 예측력을 보여, 이 라인에서는 **공정 경로 자체가 불량의 핵심 정보**임을 확인했습니다. 다만 둘을 합친 모델의 향상폭은 표준편차 범위 안이라 개선으로 보지 않았습니다.

## 결론 및 제안
- **L3_S32를 1순위 점검 대상으로 제안**합니다. 앞 라인, 투입 전 측정값, 생산 시기를 통제해도 S32 통과 시 불량률이 약 9배로 유지됐습니다.
- 특히 **불량률이 급등한 시기 구간 6~10의 S32 설비 정비·조건 변경 이력**을 우선 확인할 것을 권고합니다.
- 관찰 데이터 분석이므로 "S32가 원인"이라고 단정하지 않고, 점검 우선순위로 제시합니다.

## 한계 및 개선 방향
- **인과 미증명**: 측정 항목과 제품 정보가 익명화되어 있어, S32로 가는 부품이 다른 제품 모델일 가능성 등은 배제할 수 없음
- **선별 투입 완전 배제 불가**: 투입 전 측정값으로 S32행을 약하게나마 예측(AUC 0.58)할 수 있어, 측정되지 않은 기준에 의한 선별 가능성은 남음
- **다중 비교**: 50개 스테이션을 각각 95% 수준으로 검정해 2~3개는 우연히 걸릴 수 있음. S32는 효과가 커 영향이 없지만 나머지 4곳의 약한 신호는 우연일 수 있음
- **경로 정의의 불완전성**: 측정값 유무로 통과를 정의해, 측정값 없이 시각만 남는 스테이션 2개는 경로 분석에서 제외됨
- **시각 해상도**: 같은 시각으로 기록된 스테이션이 있는 경우가 30.4%로, 공정 순서 해석은 근사치
- **모델 비교 범위**: 30만 개 샘플 1회, 3-fold, 기본 하이퍼파라미터
- **개선 방향**: 구간 6~10에서 S32의 어떤 측정값이 변했는지 분석해 악화 원인 후보를 좁히기

## 사용 기술
Python, pandas (청크 단위 대용량 처리), numpy, scikit-learn (HistGradientBoosting, 교차검증, PR-AUC), matplotlib
통계: Wilson 신뢰구간, 표준화 평균차(SMD), Mantel-Haenszel 위험비
